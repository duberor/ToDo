# 📝 To-Do App
- 🌐 https://to-do-by-duberor.netlify.app/
Легка та розширювана SPA To-Do аплікація з кастомним роутингом, SCSS стилями та Webpack-бандлінгом.

## 🚀 Функціонал
- ⚡️ SPA з кастомним клієнтським роутингом (`history.pushState`)
- 🗂️ Маршрути: Home, About, 404
- 🎨 SCSS з підтримкою PostCSS
- 🔧 Webpack з Babel, Live Reload та оптимізацією зображень
- 🧪 Валідація форм із RegExp
- 📁 Структурований код (JS + шаблони)
